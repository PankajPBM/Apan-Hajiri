## 🛠️ Step-by-Step AI Video Production Workflow

### Option A: Fully Automated AI Avatar Walkthrough (HeyGen / Synthesia)
1. **Upload Asset:** Upload each screenshot from `manual_assets/` as full-screen presentation slides.
2. **Select Avatar:** Choose a professional business avatar (e.g., modern corporate suit, friendly tech presenter).
3. **Position Avatar:** Set avatar to bottom-right corner ("Circle" or "Half-body" layout) so the UI remains 100% visible.
4. **Paste Script:** Copy the verbatim voiceover narration from each scene into the respective slide text box.
5. **Add Zoom / Pan:** Set HeyGen "Screen Motion" to zoom in on callouts indicated in the scene notes.
6. **Generate Video:** Export at 1080p / 60fps.

### Option B: Professional Voiceover + Video Editor (ElevenLabs + CapCut / Premiere Pro)
1. **Synthesize Audio:**
   - In ElevenLabs, select the **Adam** or **Antoni** voice model.
   - Paste the Scene-by-Scene narration text into ElevenLabs.
   - Download the generated `.mp3` audio files for each scene (labeled `scene_01.mp3` through `scene_13.mp3`).
2. **Timeline Assembly:**
   - Import the 11 PNG screenshots from `manual_assets/` into your video timeline.
   - Align each screenshot to match the corresponding audio duration.
   - Apply Ken Burns effect (subtle scale from `100%` to `106%` over the duration of the scene).
   - Add highlighted callout boxes or circular spotlights over key UI buttons as directed in the script.
3. **Add Background Music:**
   - Add a subtle corporate tech ambient track at `-22 dB` to `-24 dB` volume under the speech track.
4. **Add Subtitles / Captions:**
   - Generate auto-captions in CapCut / Premiere or use the provided script cues for synchronized lower-third captions.
